# 知研概览与学习洞察设计

## 目标与边界

将 `/overview` 和 `/insights` 从迁移占位页升级为真实、多用户隔离的产品切片。设计继承已批准的 Penpot 三档布局和“统计/报告”双页签。只呈现可由当前持久数据可靠计算的文档数、已完成问答数、笔记数、报告数、近 30 天活跃天数及每日活动，不推断阅读时长、掌握度或学习连续天数。

## 架构

新增 `InsightsService` 作为只读应用聚合层。它通过 `DocumentLibraryService`、`QaService`、`NoteService` 和 `ReportService` 的公开接口获取当前会话用户的数据，返回稳定 DTO；浏览器和路由不直接读取 SQLite、历史 JSON 或用户目录。报告生成复用现有确定性报告能力，报告记录继续由 `ReportService` 管理。

API 为：`GET /api/v1/overview`、`GET /api/v1/insights/stats?days=30`、`GET/POST /api/v1/insights/reports`、`GET /api/v1/insights/reports/{id}`、`GET /api/v1/insights/reports/{id}/download?format=md|docx`。所有用户身份来自 HttpOnly 会话；生成报告必须通过 CSRF。下载使用服务端生成的安全文件名，不暴露绝对路径。

## UI 与状态

概览包含真实指标卡、最近文档和继续学习入口。无数据时给出导入文档/开始问答的明确操作。学习洞察以 URL `tab=stats|reports` 保存页签；统计使用可访问的文本与 CSS 柱形列表，报告页支持生成、历史、查看和两种下载。加载、空、错误、生成中状态不依赖颜色表达。

桌面保持最大 1200px 双列；平板在每列不足 320px 时改单列；手机单列且交互目标至少 44px。所有图表值同时提供文本，避免只靠视觉高度传达。

## 失败与演进

聚合读取失败返回统一安全错误，不返回路径、用户 ID 或堆栈。缺失报告返回 404。未来可在保持 DTO 兼容的前提下把聚合计算替换为事件表、物化视图或分析服务；当前实现不创建不可逆的数据模型，也不跨用户缓存。

成功的洞察响应与报告下载设置 `Cache-Control: no-store`。React Query 缓存键包含
当前用户名；报告生成捕获发起时的用户身份，延迟返回不能写入新登录用户的缓存。
指标是“当前保留记录”的统计，删除笔记或建立文档删除围栏后相应记录即不再计入。

## 验收

后端测试验证用户隔离、删除/围栏语义、空状态、活动聚合、CSRF、404 与下载；前端测试验证真实数据、页签 URL、空/错/加载状态和报告动作；构建、回归、三档视口及深度冒烟通过。
