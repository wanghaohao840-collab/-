# 知研浅色知识感界面设计

日期：2026-09-09

## 目标与依据

将知研的登录页、应用外壳、首页、智能问答和文档库调整为用户参考图左侧的 Style A 极简知识感。用户已确认视觉方向与先完成四个主要页面、再接入记忆和知识图谱的顺序。本文件把已确认方向细化为可验收的设计，供实现前审阅。

- `C:/Users/11272/OneDrive/桌面/简历/ChatGPT Image 2026年9月7日 22_01_54.png`：仅左侧浅色方案作为本轮视觉参考。
- `PROJECT_KNOWLEDGE.md` 与当前 `web/src`：确定实际业务边界和数据能力。

参考图是多个页面的展示拼版。产品保留独立路由，不将所有页面缩成一张长图；正式页面中的字号、点击区域和信息密度按照实际使用尺寸设计。

## 方案选择

采用现有 React 前端的布局与组件升级方案，继续调用现有 FastAPI 服务。仅修改配色无法解决现有首页的信息层级和问答阅读空间问题；另起一个独立前端则增加认证、路由和数据连接的重复工作。此次保留现有业务接口，重点更新视觉、布局与内容表达。

旧产品文档中的 Penpot 设计源代表此前设计。本轮用户提供的左侧参考图是新的视觉方向依据。实施时应同步维护仓库设计说明与 token 契约，不宣称未实际同步的 Penpot 画板已更新。

## 首版范围

包括：登录页；注册页共享视觉；侧栏与顶栏；学习首页；智能问答；文档库；受共享样式影响的其他页面回归检查。

学习洞察首版沿用真实活动数据与现有功能，获得共享视觉的一致性。独立记忆页面、知识图谱页面、掌握度算法、知识覆盖率、实体关系接口和记忆检索接口均属于后续独立功能设计。

不新建营销官网、价格页、订阅体系或文件夹功能。参考图中的营销导航、文件夹列表和装饰性数字不构成此次新增业务需求。

## 应用外壳

桌面侧栏约 216px，顶部为知研品牌，导航采用一致的线性图标、文字和浅绿色选中背景。保留现有全部路由入口与退出功能，不因参考图没有画出某个功能就移除它。

顶栏降低视觉重量，展示当前页面上下文和真实用户名。搜索入口若出现，应链接到现有检索页面；不增加没有交互结果的搜索框、通知按钮或头像菜单。

主区最大宽度约 1280px，留出 24–32px 内边距。问答页面可使用主区全部可用宽度。宽屏不把内容拉成难以阅读的超长行。

移动端保留现有底部导航和更多抽屉，保持返回焦点和键盘导航行为。正文不得被底部导航或输入框遮挡。

## 登录与注册

桌面采用左侧品牌展示、右侧表单的双栏构图。左侧使用暖白底色与很淡的绿色光晕：

- 品牌：知研。
- 品牌说明：让知识在时间中沉淀。
- 主标题：让每一次阅读／成为长期的知识资产。
- 正文：与文档对话，留下有来源的笔记，让学习持续积累。
- 装饰：半透明悬浮书页、层叠纸张与低饱和自然意象，呼应参考图。

装饰不得承载假用户记录或假同步状态。删除当前介绍中的无依据“已同步”状态，将 `document_id` 等实现术语从用户介绍文案中移除。

右侧表单保持真实认证流程、字段标签、错误提示、密码可见性和登录后返回目标页。注册页使用同一视觉体系。移动端缩短介绍区域并隐藏大型装饰，表单保持可直接操作。

书页插画使用本地静态资源；若采用生成图片，通过 imagegen 制作纯装饰图，再检查与压缩，不让生成图片承担品牌文字或表单内容。图片应设为空替代文本或标记为装饰。

## 学习首页

顶部显示“你好，{username}”和“今天继续构建你的知识体系”。用户名来自当前认证状态，不写死 David。右侧保留“导入文档”主操作。

桌面主体分为两层：

1. 上层为学习积累趋势卡、知识资产卡、最近学习卡，按可用宽度排布。
2. 下层为最近文档与继续提问内容区，提供明确的下一步操作。

学习积累趋势卡使用 `Overview.stats.activity` 的实际数据，标题为“近 30 天学习活动”，展示每日活动曲线和活跃日。曲线不称为掌握度或知识成长百分比；总量为零时展示真实空状态。

知识资产卡展示 `document_count`、`completed_question_count`、`note_count` 和 `report_count`，分别标注“文档”“已完成问答”“学习笔记”“学习报告”。不把问答条数或笔记数量重新命名为“长期记忆数量”。

最近学习使用 `recent_documents` 与 `recent_questions`。文档项可通过现有 document ID 链接进入问答。问题记录当前没有会话 ID，入口必须明确为“进入问答”，不伪装成恢复指定会话。

日期窗口沿用服务端 UTC 活动口径，不在前端改变归属日。趋势图需要文字摘要或可访问的数据说明，不能只依赖颜色传达信息。

请求加载中使用骨架或明确状态；失败展示错误与重试；新用户展示“导入第一篇文档”和“开始问答”，不填充示例数据。

## 智能问答

桌面目标布局是学习线程、中央回答、引用证据三栏。布局根据可用宽度折叠：大屏线程栏约 200px，引用栏约 260px；中央阅读区优先保证约 480px 的可用宽度。不足时将引用收进现有抽屉，再按需折叠线程栏。

会话列表显示名称改为“学习线程”；新建、选择、分页、删除仍对应现有会话行为。中央欢迎语改为“从一个问题，开始理解”，说明当前绑定的文档范围。

回答区域使用白色背景、克制的分隔和易读行距。输入框位于底部，与正文分层；保留文档范围、回答模式、提交限制和输入法组合状态保护。长回答滚动时不被输入框遮挡。

右栏主标题为“引用证据”，可辅以较小的 Evidence。使用接口真实 `citation_id`、文档名称、页码、原文片段与 reference；保留复制引用、记录引用为笔记等现有入口。非 PDF 没有页码时不造页码。

执行状态区域名称为“回答进度”。只展示当前接口提供的状态：普通回答等待期间为“正在查找并组织答案”；摘要任务可展示真实 stage 与 progress。没有细分事件时不按定时器模拟检索、记忆和推理步骤，也不展示未经定义的相关度百分比。

保留失败重试、重连、历史消息分页、来源抽屉、焦点恢复及记笔记功能。引用为空时解释当前状态，不绘制虚假的来源卡片。

## 文档库

中文主标题保留“文档库”，副标题为“每一次阅读，都有迹可循”。上传按钮使用墨绿主按钮，工具栏与列表统一为白色容器、轻边框和充分行间距。

首版以清晰列表为主：文档图标、名称、实际可用元数据和操作入口。长名称换行或截断后应能获取完整名称。移动端转换为纵向信息块，操作按钮不挤压标题。

状态沿用后端真实导入与解析状态，展示导入进度、失败原因、重试和取消入口。不把“导入完成”改成“已理解”。关联笔记数量和最近学习时间只有在文档接口确实提供时才展示，本轮不为这些字段新增聚合 API。

保留当前批量上传、文档选择、进入问答、任务历史、分页与删除确认，不从参考图推断已有文件夹、收藏或标签能力。

## 验收

视觉检查使用现有 Playwright 三档：1440×1024、1024×768、390×844，并补充 320px 宽度的溢出检查。正式页面应呈现参考左侧的明亮纸张感、墨绿点缀和清楚层级，不追求展示拼版中的微小字号。

- 检查登录和四个工作区页面的完整截图，包含长标题、长回答和空数据。
- 检查登录、返回原页面、退出、移动导航、文档导入、问答来源、记笔记和删除确认。
- 对改变的行为扩展现有测试；纯视觉调整主要由截图与浏览器检查覆盖。
- 运行前端类型检查、lint、单元测试与构建，运行受影响的端到端测试。
- 使用 token 生成器的 `--check` 验证生成物同步。
- 改动共享样式后抽查笔记、检索、洞察和学习中心，确认样式没有外溢。
- 截图基线必须在人工视觉检查后更新；测试通过不能代替视觉验收。

当前工作区已有大量未提交的其他功能改动，执行基线必须记录实际起点和已有失败。本设计不把这些改动归为本轮成果。

## 后续功能的进入条件

记忆摘要需要可查询、可解释且有来源的真实记忆契约；知识图谱需要经过用户与文档作用域过滤的实体关系及证据接口。满足条件后另行设计节点交互、筛选、空状态与性能限制。

这两项尚未完成时，首版不显示虚假的记忆卡片或可点击但无内容的知识图谱导航。首版完成标准是四个主要页面的视觉与使用体验统一，不包含图谱和记忆服务的新增实现。
