# Hello-Agents 学习证据驱动的多岗位简历增强设计

## 目标

将候选人对 Datawhale `hello-agents` 的系统学习与代码实践加入现有经历库，并依据五份既有 JD 的关注重点分别增强对应证据矩阵和 PDF 简历。所有增强版均作为新文件生成，不覆盖现有简历。

## 已确认事实

- 学习时间：2026.05.10 - 2026.06.25。
- 系统阅读并理解 `hello-agents` 全部章节。
- 实际运行、调试过配套代码。
- 实践包括第十一章中的部分 SFT/GRPO 示例代码。
- 可以使用的课程范围包括：智能体与 LLM 基础、ReAct、Plan-and-Solve、Reflection、主流框架实践、HelloAgents 自研框架、Memory/RAG、上下文工程、MCP/A2A/ANP、Agentic-RL 与智能体评测。

## 证据边界

可以表述：

- 系统学习、运行和调试教程配套代码。
- 理解经典 Agent 范式、框架结构、Memory/RAG、Context、协议与评测方法。
- 运行并调试部分 SFT/GRPO 示例，形成 Agentic-RL 基础实践。

不得表述：

- `hello-agents` 仓库贡献者或核心开发者。
- 独立设计训练数据、奖励函数、训练方案或训练框架。
- 完整复现全部 SFT/GRPO 流程或取得未经提供的训练指标。
- 生产级 Agentic-RL、多模态训练、论文或真实业务算法效果。

## 方案

采用分层定向增强。

### 经历库

新增“Datawhale Hello-Agents 智能体系统学习实践”，记录时间、学习范围、代码实践、可迁移能力和责任边界。该经历属于开源课程学习实践，不归类为个人项目、开源贡献或工作经历。

### JD 矩阵

更新五份现有矩阵，保留原始匹配结论，并增加 Hello-Agents 证据对匹配度的影响：

1. 物联网应用软件开发：强化 Python、技术预研、文档阅读和工程学习，不改变 C/C++ 缺口。
2. 小红书跨境交易 AI 研发：强化 AI 工具、Agent 设计、问题拆解与评测，不改变电商支付、金融和分布式生产缺口。
3. 小红书 AI 电商研发：强化 Agent 范式、框架选择、Context/Memory 和 AI 研发方法，不虚构电商业务指标。
4. 小红书 C 端 Agent 算法研发：将“无 Agent Harness / 无 RL”调整为“具备系统学习与部分示例实践，但缺少独立算法研发、训练指标和业务效果”。
5. 小红书多模态统一模型与创作 Agent：增强上层 Agent 与部分 SFT/GRPO 学习证据，但保留多模态基座、视觉生成、MoE、强化学习独立研发和论文缺口。

### PDF 简历

生成五份新文件，文件名追加“HelloAgents学习增强版”。

- 两份 Agent 岗简历：增加独立“Agent 系统学习实践”小节，使用 3-4 条可验证表述。
- AI 电商与跨境交易版本：使用压缩的小节或 1-2 条学习实践，突出框架、Context/Memory、评测和 AI 工具判断。
- 物联网版本：仅保留一条 Python Agent 系统学习与技术预研证据，避免削弱 C/C++ 岗位主线。
- 新闻后端项目继续保留为学习项目，不因新增课程经历而升级其完成状态。

## 内容优先级

### Agent 岗

1. ReAct、Plan-and-Solve、Reflection。
2. LangGraph 状态、节点、边与条件路由；HelloAgents 的统一 LLM、消息、Agent 和工具接口。
3. Memory/RAG、Context Engineering、MCP/A2A/ANP。
4. Agent 评测方法。
5. 部分 SFT/GRPO 示例代码运行与调试。

### AI 应用与后端岗

1. Python 代码运行与调试。
2. Agent 框架分层、工具接口、状态管理和工程取舍。
3. Context/Memory/RAG 与评测意识。
4. SFT/GRPO 仅在岗位直接相关时出现。
